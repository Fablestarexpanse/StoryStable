# Context Engine

Before any agent request, the creator can inspect and edit the context set:
current note/scene, linked entities, prior/next scenes, character states,
relevant canon, references, selected text, token estimate, and local/cloud
destination. (Spec section 8.3; PRODUCT_SPEC_V0.2 section 10.4.)

The truth/knowledge layer (world truth vs character belief vs audience
knowledge) gates what agents may reveal, preventing spoilers and omniscient
dialogue.

Implementation arrives in Phase 3.
