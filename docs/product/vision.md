# Vision

A local-first creative production environment in which Markdown world
knowledge, screenplay/scene intent, visual references, generated media,
MiniMax H3/ComfyUI rendering, review, and editorial assembly share one linked
production model while remaining portable and inspectable.

Primary flow: **WORLD → STORY → STUDIO → CUT**.

Full product statement: PRODUCT_SPEC_V0.2 sections 1-2 in
[../specs/build-spec-v0.2.md](../specs/build-spec-v0.2.md). v1 success
criteria live in PRODUCT_SPEC_V0.2 section 16 and spec section 29.
