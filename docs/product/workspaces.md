# Workspaces

Four top-level workspaces (spec section 2; PRODUCT_SPEC_V0.2 sections 3-8):

- **WORLD** - canon, notes, graph, relationships, timeline, research, references.
- **STORY** - screenplay, outline, sequences, scenes, beats, moments, branches, reveals.
- **STUDIO** - visual development, boards, shots, references, ComfyUI, H3, takes, review.
- **CUT** - animatic/edit, audio, versions, markers, review, export.

Persistent global surfaces: command palette, search, library, render queue,
agents/context inspector, notifications/problems, project health.

Rule: do not promote Library, Agents, Queue, Settings, or References to
top-level workspaces without user-testing evidence.
